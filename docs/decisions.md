# 実装に引き継いだ判断

赤ペン第1〜6稿と最後の指示を反映。ユーザーは赤ペンの終了と実装開始、Ryu-kokuでの別リポジトリ作成を指示。

- 別リポジトリ、Astro＋TypeScript、Cloudflare Pages向け静的サイト。
- 日本語で高校生を中心に伝わる軽やかな表現。高校生だけに利用制限はしない。
- 参考は `https://hidane.app/`。中央見出し、丸い形、余白、縦の機能紹介を参考にする。文章・ロゴ・画像は流用しない。
- 明るい黄緑と濃い緑。少し傾いた図形のポップなUI。
- 最終見出し：「筋トレ入力を、サクッとスワイプ。」
- スワイプ → 成果グラフ → 友達共有の順。**3つを同じ大きさの説明図付きで縦並びにする**。スワイプを誇張せず、順番で最初に伝える。
- 記録の手軽さが主な価値。友達との競争は補助的な気分で、ランキングや対戦の新機能は追加しない。
- 中央の見出しと、その下の説明図。メイン導線はページ内の機能紹介。
- App Store／Google Playの配布案内は末尾だけ。未確認のURLは作らず、片方ずつ設定できる。
- メール登録・アクセス解析・広告・外部フォントは初版では実装しない。
- 記録には重量と回数の入力が必要。スワイプだけで自動入力できるとは書かない。
- グラフは選択したメニューの完了セットに記録した重量の合計。回数を含めず、筋力や体型の改善を保証しない。
- アプリ画面の捏造はせず、LP独自の説明イラストであることを明記する。
- リポジトリは公開範囲の指定がないため非公開で作成。自動コミットはしない。

事実確認元：アプリリポジトリのREADME、`mobile/src/components/SwipeCard.tsx`、`mobile/src/app/records.tsx`、`mobile/src/app/rooms.tsx`。ビルド設定やコードの存在だけで、ストア公開済み・共有が本番で利用可能とは扱わない。
