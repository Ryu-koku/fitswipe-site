# 公開前チェック

初版はローカル実装。デフォルトで検索登録不可・ストアリンク無効。

- [ ] App Store／Google Playの正式な掲載と所有者を確認し、使えるURLだけ設定する。
- [ ] リンク先が未公開・内部テスト限定の場合、一般配布として案内しない。
- [ ] 配布版でスワイプ、グラフ、共有が説明どおり動くことを確認する。
- [ ] 共有サーバー接続設定を確認。未稼働なら共有の紹介やFAQを実態に合わせる。
- [ ] 未成年の利用条件も含め、アプリの正式なプライバシーポリシー・規約・データ保持と削除の案内を用意する。
- [ ] 問い合わせ先と運用担当を確認し、`PUBLIC_SUPPORT_EMAIL` を設定する。
- [ ] ホスティングのログなどの取り扱いを確認し、データの扱いページの準備中表現を実態に合わせる。
- [ ] 本番ドメインとCloudflareの設定・公開権限を確認する。
- [ ] ストアの独自案内を使うか、正規バッジを使うかをブランド規約に照らして確認する。
- [ ] SNS向けOG画像（`public/social.png`）と本番URLのメタ情報を確認する。
- [ ] 検証が終わってから `PUBLIC_SITE_URL` と `PUBLIC_INDEXABLE=true` を設定する。
- [ ] `pnpm check`、`pnpm test`、`pnpm build`、`pnpm test:e2e` が成功する。
- [ ] コミット・pushは明示的な承認を得てから行う。
- [ ] Cloudflare PagesのGit連携と公開は、公開条件を満たした後に行う。
